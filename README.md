## 📌 About the Project

A **Family Wallet System** developed as a project for the *Software Testing Practicum* course.

This system facilitates family savings management by allowing members to record transactions, monitor balances, track contributions, and view financial summaries through a centralized web-based platform.

---

## ✨ Key Features

* 👤 User authentication and role management
* 💵 Savings deposit and withdrawal recording
* 📈 Financial dashboard and balance monitoring
* 📜 Transaction history management
* 🏆 Contribution leaderboard tracking
* 📱 Responsive mobile-first user interface
